# Ngedate

Aplikasi chat DM berbayar dengan host: bayar koin per pesan (dibayar saat host membalas),
gift dengan animasi, dan nomor WhatsApp host terbuka setelah total gift mencapai syarat.

| Folder | Isi | Status |
|---|---|---|
| `backend/` | API + realtime (Express, PostgreSQL, socket.io) | Job 1–2 ✅ |
| `app/` | Aplikasi Android **Amora** (Expo) | Job 2 ✅ (chat di Job 3) |

Detail backend, aturan ekonomi, dan daftar API: [backend/README.md](backend/README.md).
